#💰 AI Personal Expense Analyzer
A smart, AI-Powered personal expense tracking and analysis application designed to help users track, categorize, and gain insights into their daily spending habits.
---
## 🚀 Features
* **Expense Tracking:** Easily log daily expenses with details like date, amount, category, and description.
* **Smart Categorization:** Automatically group expenses into categories like Food, Transport, Bills, and Entertainment.
* **AI Insights:** Get AI-driven analysis and budget suggestions.
* **Visual Reports:** Interactive graphs and summaries for visual tracking.
